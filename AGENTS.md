# Orientações do projeto

Projeto de estudos de HTML e CSS: Aula 5.

## Contexto compartilhado

Antes de trabalhar, leia `.agente/README.md`, `.agente/rules/projeto.md` e
`.agente/context/projeto.md`. Consulte os demais documentos conforme a tarefa.
As instruções explícitas do usuário têm prioridade sobre as convenções locais.

## Trabalho

- Responda em português do Brasil.
- Preserve o conteúdo existente e faça alterações proporcionais ao pedido.
- Prefira HTML semântico e CSS simples, com atenção à acessibilidade e responsividade.
- Não adicione frameworks ou ferramentas de build sem necessidade do projeto.
- Valide as alterações com os recursos disponíveis e informe o que foi verificado.
- Registre decisões duradouras e contexto relevante nas pastas de `.agente/`.
- Não registre senhas, tokens ou dados pessoais nos documentos.
