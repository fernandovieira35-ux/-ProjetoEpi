# Verificação de entrega

Marque somente verificações efetivamente realizadas. Use “não se aplica”
quando necessário e registre qualquer verificação pendente.

- [ ] O resultado atende ao pedido.

- [ ] HTML e CSS afetados foram revisados, quando aplicável.
- [ ] A interface foi verificada em celular e desktop, quando aplicável.
- [ ] Navegação por teclado e rótulos foram conferidos, quando aplicável.
