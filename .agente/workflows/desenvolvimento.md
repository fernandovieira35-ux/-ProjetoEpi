# Desenvolvimento

1. Entender o pedido e ler os arquivos envolvidos.
2. Verificar o contexto e preservar alterações já feitas pelo usuário.
3. Planejar brevemente; usar `../templates/plano.md` se houver várias etapas.
4. Implementar a menor solução completa para o pedido.
5. Conferir caminhos, estrutura, estilos e comportamento afetado.
6. Usar `../checklists/entrega.md` e informar limitações de validação.
7. Atualizar o contexto apenas quando houver mudança relevante.
