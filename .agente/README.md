# Harness do projeto

Esta pasta reúne instruções e contexto reutilizáveis entre sessões de trabalho.
O nome `.agente` é uma convenção deste projeto.

## Fluxo de leitura

1. Ler `AGENTS.md` na raiz e `rules/projeto.md`.
2. Consultar `context/projeto.md` e `tasks/backlog.md`.
3. Para tarefas maiores, criar um plano em `plans/` usando `templates/plano.md`.
4. Implementar conforme `workflows/desenvolvimento.md`.
5. Verificar com `checklists/entrega.md`.
6. Atualizar tarefas e registrar decisões relevantes em `memory/decisoes.md`.

Documente apenas o necessário. Ajustes pequenos não exigem um novo plano.
`skills/` desta pasta fica reservada para procedimentos documentais.
As skills executáveis pelo Antigravity ficam em `../.agent/skills/` e suas
regras em `../.agent/rules/`, separadas deste harness.
