# Transcol · Gestão de EPIs

Sistema web para estoque, cadastros, entregas, validade de EPIs, relatórios e impressão.
Desenvolvido por Fernando Vieira.

Com o servidor local ativo, acesse **http://127.0.0.1:5501/estoque/**.
A página da raiz redireciona para o sistema. Demonstração: **http://127.0.0.1:5501/estoque/?demo=1**.

- [Guia do sistema e configuração](estoque/README.md)
- [Manual de uso](estoque/docs/manual.html)
- [Implantação](estoque/docs/implantacao.md)
